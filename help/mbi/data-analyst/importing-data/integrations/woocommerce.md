# [!DNL WooCommerce]を接続

>[!NOTE]
>
>[管理者権限](../../../administrator/user-management/user-management.md)が必要です。

![WooCommerce ロゴ ](../../../assets/WooCommerce-Logo.jpg)

優れたパフォーマンスを確認したり、最も価値のある獲得ソースやチャネルを特定したりするために、 [!DNL WooCommerce] データを[!DNL Commerce Intelligence]に接続すると、これらの質問に答えることができます。

[!DNL WooCommerce] データベースは[!DNL MySQL]に基づいています。[直接接続](../integrations/mysql-via-a-direct-connection.md)、[[!DNL cPanel]](../integrations/mysql-via-cpanel.md)または[経由`SSH tunnel`](../integrations/mysql-via-ssh-tunnel.md)で[!DNL Commerce Intelligence]に接続できます。 Adobeでは、最も安全なSSH方式を使用することをお勧めします。 SSH ホスト キーの検証については、[SSH ホスト キーの検証](../integrations/ssh-host-key-verification.md)を参照してください。
